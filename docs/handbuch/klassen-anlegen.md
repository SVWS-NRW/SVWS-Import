# Klassen anlegen

[Zurueck zum Inhaltsverzeichnis](../index.md) | [Verbindung herstellen](verbindung-herstellen.md)

## Ziel

Neue Klassenstammdaten ueber eine Importdatei anlegen.

## Schritte

1. Oeffnen Sie die Kachel Klassen.
2. Laden Sie die vorbereitete Datei.
3. Pruefen Sie Datenvorschau und Mapping.
4. Beheben Sie Fehler in Pflichtfeldern.
5. Starten Sie den Import.

## Qualitaetscheck

- Klassenbezeichnungen konsistent
- Jahrgangsbezug korrekt
- Keine doppelten Eintraege
