# Import-Assistent nutzen (Schritt fuer Schritt)

[Zurueck zum Inhaltsverzeichnis](../index.md) | [Verbindung herstellen](verbindung-herstellen.md)

## Ziel

Sie fuehren einen gefuehrten Import in klaren Schritten durch.

## Schrittfolge im Assistenten

1. Importmodul waehlen und Datei hochladen
2. Rohdatenvorschau kontrollieren
3. Spalten-Mapping anpassen
4. Validierung pruefen und Fehler korrigieren
5. Import senden und Ergebnis auswerten

## Hinweise zur Nutzung

- Bei unklaren Fehlern zuerst die Quelldatei pruefen.
- Kritische Felder immer manuell kontrollieren.
- Bei grossen Datenmengen mit Testausschnitt starten.
