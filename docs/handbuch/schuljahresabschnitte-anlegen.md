# Neue Schuljahresabschnitte anlegen

[Zurueck zum Inhaltsverzeichnis](../index.md) | [Verbindung herstellen](verbindung-herstellen.md)

## Ziel

Neue Schuljahresabschnitte in SVWS anlegen.

## Schritte

1. Oeffnen Sie die Kachel Schuljahresabschnitte anlegen.
2. Wechseln Sie zur Funktion fuer neue Eintraege.
3. Erfassen Sie die benoetigten Werte fuer den Abschnitt.
4. Speichern Sie den neuen Eintrag.
5. Pruefen Sie, ob der Eintrag in der Liste erscheint.

## Pruefpunkte

- Schuljahr korrekt
- Abschnitt korrekt (z. B. 1 oder 2)
- Keine doppelten Kombinationen
